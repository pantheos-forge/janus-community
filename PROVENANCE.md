# Provenance

Janus Core is derived by **extraction** from a proprietary predecessor
pentesting agent (the author's own work), which was never modified in the
process. The domain-agnostic nucleus was generalized from the predecessor's
runtime; the domain-specific layers were dropped.

That predecessor was a real, in-production agent. Pentesting was simply the
first domain built this way — the template proved itself there before becoming
a general-purpose system.

The predecessor carries no separate open-source license and is not distributed.
